# AetherFlow Documentation Index

Единая точка входа в документацию проекта.

## Структура

| Раздел | Назначение |
|---|---|
| `01_Versions` | История и состояние каждой версии |
| `02_Roadmap` | План разработки и последовательность фаз |
| `03_Design` | Game Design Document и дизайн-системы |
| `04_Gameplay` | Игровые механики и правила |
| `05_Technical` | Архитектура, pipeline, данные и технические решения |
| `06_Map` | Карта, layout, дороги, terrain, navigation и map-specific данные |
| `07_Art_UI_Audio` | Визуал, UI и аудио |
| `08_Testing_QA` | Тесты, validation, regression и QA |
| `09_Decisions` | Зафиксированные архитектурные и дизайн-решения |
| `10_Releases` | Release notes, package contents и release status |

## Правила документации

1. Текущая версия определяется через `VERSION.txt` в корне проекта.
2. Документы конкретной версии находятся в `01_Versions/<version>/`.
3. Дизайн игры хранится в `03_Design`, а механики и их технические правила — в `04_Gameplay`.
4. Карта и её измеримые свойства документируются в `06_Map`.
5. Фактические результаты тестов документируются в `08_Testing_QA`.
6. Архитектурные решения, которые должны оставаться стабильными, фиксируются в `09_Decisions`.
7. Завершённые версии и их пакеты фиксируются в `10_Releases`.
8. Исторические материалы не удаляются без необходимости; устаревшие документы помечаются как historical/deprecated.
