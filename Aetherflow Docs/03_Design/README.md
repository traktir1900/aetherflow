# AetherFlow — Design / GDD

Единый раздел игрового дизайна проекта.

## Что хранится здесь

- vision и fantasy проекта;
- core game loop;
- правила матча;
- Dominion-подобная структура;
- game modes;
- objectives и их дизайн-контракт;
- victory / defeat conditions;
- progression;
- economy design;
- player experience;
- high-level balance principles;
- GDD и отдельные design specifications.

## Разделение ответственности

`03_Design` отвечает на вопрос **что и зачем должно существовать в игре**.

`04_Gameplay` отвечает на вопрос **как конкретная игровая механика должна работать**.

`05_Technical` отвечает на вопрос **как это реализовано технически**.

`01_Versions` отвечает на вопрос **что изменилось в конкретной версии**.

Это разделение не должно смешиваться без необходимости.

## Документ-источник

Будущий основной GDD следует называть `GDD.md`. Детальные системы оформляются отдельными файлами с понятными именами, например:

- `GAME_VISION.md`
- `GAME_MODES.md`
- `MATCH_RULES.md`
- `ECONOMY_DESIGN.md`
- `PLAYER_EXPERIENCE.md`

До появления отдельных документов их содержание не дублируется искусственно.
