## Anti-camping refinement implemented

`core/gameplay_cover.py` now uses the shared `core.cover_analysis.optimize_cover` system and then enforces two tactical distance rings:

- near flank: 13–18 m from objective center;
- deep flank/retreat: 21–28 m from objective center;
- pair separation: at least 10 m;
- direct radial approach/retreat lane remains open;
- capture platform receives a hard exclusion zone;
- exactly two objective-cover pieces are targeted per objective;
- fallback logic guarantees that a second fallback piece is deep, never another near-ring piece.

The code therefore no longer relies on the previous 15.5 m + 15.5 m symmetric placement.

## Altar data-model gap

The audit still reports `AltarObstacles: 0`. The current generator uses `CoreCover_*` for central blocking and does not yet create a separate `Altar_Obstacle_*` category. This remains a tracked data-model task; it is not being solved by renaming unrelated cover.
