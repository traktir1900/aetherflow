## Gameplay rules

All resource foundation objects are:

- visual-only;
- non-blocking for navigation;
- non-blocking for LOS;
- derived from the authoritative layout;
- generated as exact X-mirrored pairs.

The core rule is:

> Every team-relevant resource opportunity on one side must have an equivalent mirrored opportunity for the other team.

No independent Blue/Red resource coordinates are maintained.
